# QuickSend v2.1 安全审查记录

**状态：预览版已发布，验收待完成。** v2.1.0 的接收目录选择、保存路径展示、桌面端打开文件夹与安装包构建已通过代码 CI 和 release workflow。真实设备文件存储/安装行为尚未验证；本文不是独立安全审计或稳定版批准。

## v2.1 文件保存范围

- 收到的文件保存至用户选定的接收根目录下 `QuickSend/Received/<transfer-id>`；桌面默认系统 Downloads，Android/iOS 默认应用 Documents/Downloads 沙盒目录。移动端通过系统分享菜单导出到公开位置。
- 选择目录后只影响后续传输，不会移动旧文件。根目录无法访问、权限不足或磁盘不足时，不应显示成功；保存失败需删除对应临时目录并显示中文错误。
- 传输编号为 UUID v4，路径需要跨平台校验；独立 transfer-id 子目录避免不同传输间重名覆盖。桌面端打开文件夹使用操作系统文件管理器；移动端应通过系统分享菜单导出，不假设应用沙盒路径可从文件浏览器访问。

## 既有模式的风险

- **严格保密模式**：文件内容、名称、相对路径、SHA-256 清单端到端加密；中继仍可见地址、设备/群组元数据、时间和文件大小。
- **高速模式**：文件内容以明文经过局域网中继，文件清单同样公开给中继；中继或流量监听者可能读取/修改内容。接收端散列校验不能抵御同时篡改内容与清单的恶意中继。禁止用于敏感数据。
- **UDP 自动发现**：设备名称/IP/端口广播未经认证，可被伪造或观察；它只显示候选主机，不建立身份信任。
- **发布包**：Windows/macOS/Android 生产签名身份未配置；iOS 需发布者自己的 Apple 团队与配置文件。不可伪造或共享发布者签名凭据。

## 稳定版前必须检查

1. 检查 SharedPreferences 持久化的自定义路径在重启后仍正确；恢复默认能清除自定义设置，且 UI 显示最终绝对路径。
2. 检查 Android SAF/外置存储权限、iOS 文件提供商、Windows Unicode/空格路径、macOS sandbox 与 Linux 挂载点兼容。拒绝访问、卸载磁盘或路径被删除时应明确失败，不可误报接收成功。
3. 检查目录符号链接/竞态、预先存在的 transfer-id 目录、重复路径、重名文件、零字节/大文件及取消清理。
4. 实测 Windows installer、Linux DEB 与 macOS DMG 的安装/卸载、依赖、快捷方式和升级，不应清理用户 Downloads。
5. 在真实 OS 设备和干净虚拟机完成端到端传输；CI 不能证明操作系统文件选择器或沙盒行为正确。
6. 在独立安全审查完成前，不得将预览版称为稳定或生产就绪，不用于高风险/受监管文件。
